# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability:
1. Do NOT open a public issue.
2. Email the maintainer with details (impact, reproduction steps, environment).
3. You will receive a response within 7 business days.

## Supported Versions
This is academic/research code; only the `main` branch receives fixes.

## Best Practices for Users
- Run in isolated environments (e.g., conda env, venv)
- Inspect notebooks before executing
- Do not run untrusted code blocks

## Disclosure
Responsible disclosure is appreciated. Public advisories may be added if needed.
