# Contributing Guide

Thanks for your interest in contributing!

## Ways to Contribute
- Report bugs (GitHub Issues)
- Suggest enhancements
- Improve documentation
- Add reproducible examples or tests

## Development Setup
1. Fork the repository
2. Clone your fork
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Commit changes with clear messages
5. Push and open a Pull Request (PR)

## Pull Request Checklist
- One focused change per PR
- Add/update documentation if needed
- Avoid committing large data files or generated outputs
- Ensure notebooks run top-to-bottom without errors

## Issue Reports
Include:
- Description of problem
- Steps to reproduce
- Expected vs actual behavior
- Environment (OS, Python, ArcGIS Pro version)

## Code Style
- Prefer clarity over brevity
- Use meaningful variable names
- Keep paths configurable (avoid hardcoding personal drive letters if possible)

## Notebooks
If adding/modifying notebooks:
- Clear unneeded large outputs
- Keep execution count ordered
- Add short markdown headers explaining each step
